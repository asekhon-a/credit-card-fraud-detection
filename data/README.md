Project Data
This project uses a credit card transaction dataset containing 100,000 transaction records and 43 original variables.

The raw dataset is not included in this repository.

The project notebooks demonstrate the process used to inspect, clean, prepare, and analyse the dataset.

Dataset Structure
The dataset includes information related to:

Transaction characteristics
Customer and account attributes
Transaction channels
Merchant categories
Geographic indicators
Authentication behaviour
Historical transaction behaviour
Fraud classification
Fraud type
Recorded fraud losses
Target Variable
The primary target variable is is_fraud:

0 represents a legitimate transaction.
1 represents a fraudulent transaction.
The dataset is highly imbalanced, with fraudulent transactions representing approximately 2.06% of all transactions.
